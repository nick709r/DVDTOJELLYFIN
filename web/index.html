MUSIC CDS

Album details

MusicBrainz read-only lookups do not require an API key. AutoDisc identifies itself with a User-Agent; adding a contact email helps MusicBrainz reach you if there is an issue.

When enabled, a successful automatic match continues without interruption. If no usable match is found, the CD job waits for you to enter a release ID or provide album and track names in the dashboard. With lookup disabled, CDs keep processing unattended with generic track names.

MusicBrainz provides album and track names for the FLAC tags and filenames. Lidarr needs these details to identify and categorize albums.

LIBRARY MANAGEMENT

Lidarr import

Set this to the shared downloads/import folder that Lidarr can read; AutoDisc creates an Artist - Album folder with numbered, tagged FLAC tracks, then asks Lidarr to match and move them into its library. If Lidarr runs in Docker, use the path as mounted inside the Lidarr container and make sure AutoDisc can access that same path. Add the artist and album to Lidarr and enable MusicBrainz lookup. The Jellyfin Music folder must match Lidarr's library root.
