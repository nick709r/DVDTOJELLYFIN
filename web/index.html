MUSIC CDS

Album details

MusicBrainz read-only lookups do not require an API key. AutoDisc identifies itself with a User-Agent; adding a contact email helps MusicBrainz reach you if there is an issue.

When enabled, a successful automatic match continues without interruption. If no usable match is found, the CD job waits for you to enter a release ID or provide album and track names in the dashboard. With lookup disabled, CDs keep processing unattended with generic track names.

MusicBrainz provides album and track names for the FLAC tags and filenames. Lidarr needs these details to identify and categorize albums.

LIBRARY MANAGEMENT

Lidarr import

Set this to the shared downloads/import folder that Lidarr can read; AutoDisc creates an Artist - Album folder with numbered, tagged FLAC tracks, then asks Lidarr to match and move them into its library. If Lidarr runs in Docker, use the path as mounted inside the Lidarr container and make sure AutoDisc can access that same path. Add the artist and album to Lidarr and enable MusicBrainz lookup. The Jellyfin Music folder must match Lidarr's library root.

VERSION 2 · TELEVISION

TV Processing

Every TV disc is staged before review and is never automatically deleted. Choose Delete unmatched tracks or Remove disc from review when you want to clear staged content.

Disabling TV detection prevents TV analysis. Disabling evidence capture does not disable TV analysis or review plans.

Current matching policy (read-only)

TV sensitivity: conservative, fixed by the V2 policy.

High confidence: ≥ 0.90 · Medium: ≥ 0.72 · Below 0.72: review required.

Episode match minimum confidence: 0.72 · Ambiguity margin: 0.12.

Low-confidence and ambiguous/multipart matches remain review-gated. User overrides are enabled and audited.

Threshold editing is intentionally locked until calibration against a representative real-disc dataset; displayed scores are evidence rankings, not probabilities.

Forget Disc?

This will permanently remove:

  • Disc history
  • Review records
  • Episode matches
  • Metadata
  • Diagnostics
  • Processing logs
  • Disc fingerprints

The disc will be treated as completely new if inserted again.

This action cannot be undone.

TV MATCHING

Delete Unmatched TV Disc

This will permanently remove:

  • Staged video files
  • Temporary metadata
  • Downloaded artwork
  • Diagnostics
  • Matching history

Published media will NOT be affected.

TV DISC REVIEW

Delete unmatched tracks?

Only tracks without confirmed episode matches will be deleted. Matched tracks and their mappings will remain staged.

This cannot be undone.

Delete Review Item

This will permanently delete the review item and all associated temporary files, staged media, metadata caches, artwork, fingerprints, and processing history.

Shared provider caches, shared fingerprints, and published media are protected.

This action cannot be undone.

Clean Up Orphaned Data

These temporary directories are not associated with a known job or review workspace. Their contents will be permanently deleted.

Published media and shared metadata caches are not included.
