LIBRARY MANAGEMENT

Lidarr import

AutoDisc names and tags every FLAC track first, then submits the album to Lidarr for a manual import using Move. Add the artist and album to Lidarr and enable MusicBrainz lookup. Lidarr must be able to read and write the same absolute incoming-folder path; the Jellyfin Music folder must match Lidarr's library root.
